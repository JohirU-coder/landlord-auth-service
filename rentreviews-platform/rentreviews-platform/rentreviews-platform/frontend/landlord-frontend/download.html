⚠️ Before you install

This app isn't distributed through the Google Play Store, so Android will show a warning when you open the downloaded file — this is expected for any app installed this way, not a sign anything is wrong.

  1. Tap the downloaded RentReviews.apk file to open it.
  2. If prompted "For your security, your phone is not allowed to install unknown apps from this source" — tap Settings, then enable Allow from this source for your browser.
  3. Go back and tap the file again, then tap Install.

This permission only applies to the app you used to download the file, and only affects your ability to install apps from outside the Play Store — it doesn't grant RentReviews any extra access to your device.

To update later, just come back to this page and download the latest version — updates install over the existing app without losing your data.
